# AI Agent Platform 使用文档

AI Agent Platform 是面向企业私有化场景的智能体配置与运行平台。它把模型、工具、
MCP 服务、Skills、Agent、会话和记忆放在同一个控制台中管理。

本手册针对仓库当前实现编写，重点回答三类问题：

- 平台怎样启动和进入；
- 每个界面能做什么、应该按什么顺序操作；
- 配置或运行异常时从哪里检查。

## 推荐使用路径

1. 在 **模型接入** 中配置供应商、模型和平台默认模型插槽。
2. 在 **Tools 目录**、**MCP 服务器** 和 **Skills 中心** 准备 Agent 能力。
3. 在 **Agent 管理** 中创建 Agent，并配置编排、能力、记忆和模型策略。
4. 先在 Agent 详情页快速测试，再到 **Agent 工作台** 正式对话。
5. 在 **记忆管理** 中审核和维护跨会话记忆。

```{note}
侧栏菜单是判断功能是否正式开放的准绳。仓库中已经实现、但当前没有菜单入口的页面，
会在[待开放功能](guide/pending-features.md)中单独说明。
```

## 系统组成

| 部分 | 位置 | 作用 |
|---|---|---|
| Web 控制台 | `frontend/live-console` | Vue 3 管理界面 |
| 平台服务 | 仓库根目录 | Spring Boot API、配置、运行时和持久化 |
| Agent 框架 | Maven 依赖 | AgentScope Java 基础能力 |
| 工作区 | `workspace`（启动脚本默认值） | SQLite、YAML、缓存和会话数据 |
