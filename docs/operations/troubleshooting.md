# 故障排查

## 控制台显示后端连接异常

- 确认后端进程正在监听预期端口；
- 查看 `logs/platform/` 中最新的错误日志；
- 确认前端代理与后端端口一致；
- 直接检查平台健康接口是否可访问。

## 模型 Ping 成功，但测试失败

- 检查上游模型名和 Endpoint Path；
- 检查认证引用是否在后端运行环境中可解析；
- 检查模型类型、请求 Body 覆盖和额外 Header；
- 查看模型调用审计中的最终 Model ID 和 Slot Key。

## Agent 提示没有可用模型

1. 在模型接入页确认模型已启用；
2. 确认对应模型插槽已绑定；
3. 使用“解析预览”检查当前组织上下文；
4. 检查 Agent 的模型策略是否覆盖到了不存在的模型或插槽。

## Agent 没有调用预期工具

- 先在 Tools 或 MCP 页面单独测试工具；
- 检查工具、MCP 服务及具体工具是否已启用；
- 检查 Agent 是否绑定了对应能力；
- 检查当前 Flow 是否支持工具调用；
- 在 Agent 工作台查看模型调用和工具调用事件。

## 找不到刚创建的资源

核对当前业务域、组织 ID、列表筛选条件和启用状态。刷新页面后仍不存在时，再检查保存
请求是否失败，以及实际使用的工作区和持久化模式。

## 记忆没有生效

- 检查记忆是否仍处于待确认或停用状态；
- 检查 Agent 的 Memory 策略；
- 使用新会话验证，排除旧上下文影响；
- 注意 Episodic 区域当前尚未接入自动摘要召回。

## MCP 无法连接

- 网络服务：检查 endpoint、传输方式、认证 Header 和网络可达性；
- `stdio` 服务：检查命令、参数、工作目录和运行时依赖；
- 使用“测试连通性”后再执行“发现工具”；
- 服务 Schema 变化时执行重新探测与同步，并检查 Schema 历史。
