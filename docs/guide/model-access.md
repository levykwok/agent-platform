# 模型接入

模型接入页负责把上游模型服务转换为平台可使用的模型资源。建议按
“供应商 → 模型 → 插槽”顺序配置。

## 1. 配置供应商

在“供应商”区域选择“新增供应商”，填写供应商 ID、显示名、类型、Base URL、
Endpoint Path、认证引用和超时等信息。保存后先执行“测试连接”。

供应商保存公共连接信息。多个模型共用同一个地址和认证时，无需重复填写。

## 2. 配置模型

可以在供应商卡片中选择“加模型”，也可以在模型目录中新增。主要字段包括：

- Model ID、显示名、上游模型名；
- 模型类型和所属供应商；
- Base URL、认证和超时覆盖；
- 是否支持视觉、工具调用等能力；
- Embedding 向量维度；
- 输入/输出价格和币种；
- 额外请求 Header 与 Body 参数。

保存后使用“Ping”检查基础连通性，使用“测试”验证实际模型调用。

## 3. 绑定模型插槽

平台插槽为 Agent 提供稳定的模型用途。为每个需要的插槽选择一个默认模型。业务域还
可以创建自定义插槽，例如 `coach_large` 或 `judge_fast`。

“解析预览”可以验证某个插槽在指定组织上下文中最终命中哪个模型。如果结果为
“未配置”，Agent 运行时也无法从该插槽获得模型。

## 4. 查看审计

审计日志可按 Model ID 和 Slot Key 查询，用于确认运行时实际选择了哪个模型，以及
定位调用失败。

```{warning}
删除供应商或模型前，先检查模型插槽和 Agent 模型策略中的引用。连接测试成功不等于
模型调用一定成功，上游模型名、请求路径和能力参数也必须匹配。
```
