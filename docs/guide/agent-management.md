# Agent 管理

Agent 管理页负责把模型和各类能力组合成可运行的智能体。

## 创建流程

选择“新建”后，配置向导包含八个步骤：

1. **基本信息**：Agent ID、显示名、描述、业务域和启用状态。
2. **编排**：选择 Flow、路由或子 Agent 等执行方式。
3. **技能**：绑定 Agent 可使用的 Skills。
4. **平台工具**：选择平台 Tools。
5. **MCP 服务器**：选择 MCP 服务及其工具范围。
6. **Memory 策略**：设置记忆读取、写入或确认策略。
7. **模型策略**：选择模型插槽并设置 Agent 级覆盖。
8. **Prompt**：设置角色、任务边界和输出要求。

可使用“上一步”“下一步”逐项检查，也可以直接点步骤标签跳转。最终选择“保存配置”。

## 编排与子 Agent

配置子 Agent 时，应明确绑定 ID、目标 Agent、角色和职责。避免多个子 Agent 的职责
完全重叠，否则主 Agent 难以稳定路由。

模型、Tool、Skill 或 MCP 是否能使用，还取决于当前 Flow 的能力支持。详情页上的能力
标记可以辅助判断，运行前仍建议做一次真实测试。

## 快速测试

选择 Agent 后，可在详情页输入测试问题并运行。推荐依次验证：

1. 纯文本模型回复；
2. 所需 Tool 或 MCP 调用；
3. Skill 是否按预期生效；
4. 多 Agent 编排；
5. 记忆写入和下次会话召回。

快速测试通过后，再到 Agent 工作台创建正式会话。
