# 记忆管理

记忆管理页用于维护 Agent 可跨轮次或跨会话使用的信息。

## 长期记忆

列表支持按关键词过滤，并提供：

- 新增、查看详情和编辑；
- 确认或拒绝待确认记忆；
- 启用、停用和删除；
- 合并重复或相近记忆；
- 根据来源 Run 查看产生记忆的执行记录。

待确认队列用于落实人工审核策略。只有确认并生效的内容才应被后续 Agent 稳定使用。

编写记忆时应保存可复用的事实或偏好，例如“用户偏好先给结论，再给依据”，不要把
一次性任务指令或敏感原文直接写入长期记忆。

## 运行记忆

页面可以刷新查看当日运行记忆，帮助判断 Agent 在执行过程中记录了什么。

## Episodic 索引

平台跨会话 Episodic 区域当前以状态展示为主，界面已明确标注“暂未接入自动摘要召回”。
因此不要把这里出现数据等同于 Agent 已经会自动召回这些内容。

## 推荐维护流程

1. 定期处理待确认队列；
2. 合并重复偏好，删除过期事实；
3. 对错误记忆先停用，再调查来源 Run；
4. 修改后用新会话验证召回，避免旧上下文影响测试结果。
