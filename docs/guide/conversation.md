# 交互问答与 Agent 工作台

## 交互问答

交互问答适合面向用户的业务问答。

使用步骤：

1. 选择业务域和 Agent；
2. 按需限定知识库文档；
3. 可上传附件或使用语音输入；
4. 输入问题，按 Enter 发送，Shift+Enter 换行；
5. 查看回答、文档来源，或使用朗读功能。

打开“显示上下文”后，可切换：

- **活动**：本轮执行事件；
- **资源**：附件、文档和产物；
- **记忆**：本轮使用的长期或情景记忆，并可反馈；
- **证据**：引用、知识图谱命中和工具调用。

左侧历史对话支持搜索、新建、刷新和删除。

## Agent 工作台

工作台更适合开发、联调和排查 Agent 行为。

1. 在左侧按业务域筛选并选择 Agent；
2. 创建或选择会话；
3. 输入消息，或添加图片后发送；
4. 展开消息中的执行步骤，查看模型和工具事件；
5. 打开“会话详情”检查上下文、日志、压缩、任务、记忆和文件。

工作台会展示工具调用开始、参数增量、工具结果、模型调用和等待用户输入等事件。出现
问题时，不要只看最终回答，应先定位最后一个成功事件和第一个失败事件。

## 入口选择

| 场景 | 建议入口 |
|---|---|
| 验证知识问答、附件、引用和朗读 | 交互问答 |
| 查看 Tool/MCP 的完整调用过程 | Agent 工作台 |
| 检查会话压缩、任务、文件和运行日志 | Agent 工作台 |
| 面向普通业务用户演示 | 交互问答 |
