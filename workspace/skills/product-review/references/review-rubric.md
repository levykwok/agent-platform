# Review rubric

- P0: blocks launch, risks incorrect data, or creates a security or compliance issue. It must be closed before launch.
- P1: makes the main path unusable, leaves a key dependency unresolved, or lacks an acceptance definition. Close it before scheduling.
- P2: experience, copy, observability, or follow-up work. Track it for a later iteration.

Acceptance criteria must be independently testable. Prefer Given / When / Then wording.
